# 노션 견적서 웹 뷰어 MVP PRD

## 핵심 정보

**목적**: 노션 데이터베이스에 입력한 견적서를 고유 URL로 클라이언트에게 공유하고 PDF 다운로드까지 제공하여, 별도 견적서 툴 없이 노션만으로 전문적인 견적 프로세스를 완결한다.

**사용자**: 노션을 업무 도구로 사용하는 프리랜서, 1인 개발자, 소규모 사업자 — 그리고 견적서 URL을 받는 그들의 클라이언트(노션 계정 불필요).

---

## 사용자 여정

```
[발행자 여정]

1. 노션 데이터베이스
   ↓ 견적서 내용 입력 (품목, 금액, 클라이언트 정보 등)

2. 서비스 대시보드 (로그인 필요)
   ↓ 노션 연동 후 견적서 목록 자동 동기화

3. 견적서 목록 페이지
   ↓ 특정 견적서 선택

4. 견적서 상세 페이지 (발행자 뷰)
   ↓ "공유 링크 복사" 버튼 클릭

5. 고유 URL 클립보드 복사 완료
   ↓ 클라이언트에게 URL 전달 (이메일, 메신저 등)

6. 완료


[클라이언트 여정]

1. 클라이언트가 고유 URL 접근
   ↓ 유효한 토큰 확인

   유효한 URL → 견적서 웹 뷰어 페이지로 진입
   만료/잘못된 URL → 오류 안내 페이지로 이동

2. 견적서 웹 뷰어 페이지
   ↓ 견적서 내용 확인

   "PDF 다운로드" 버튼 클릭 → PDF 파일 다운로드 완료
   (별도 로그인 불필요)

3. 완료
```

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|---------------|------------|
| **F001** | 노션 연동 설정 | 노션 OAuth로 계정 연결 후 견적서 데이터베이스 ID를 등록 | 노션 데이터 읽기를 위한 진입점 | 노션 연동 설정 페이지 |
| **F002** | 견적서 동기화 | 연결된 노션 DB에서 견적서 데이터를 가져와 서비스 DB에 저장 | 노션 → 서비스 데이터 흐름 핵심 | 견적서 목록 페이지 |
| **F003** | 견적서 목록 조회 | 동기화된 견적서 전체 목록을 카드/테이블로 표시 | 발행자가 견적서를 관리하는 기본 화면 | 견적서 목록 페이지 |
| **F004** | 견적서 상세 확인 (발행자) | 발행자가 견적서 내용을 미리보기 형태로 확인 | 공유 전 내용 검토 필요 | 견적서 상세 페이지 (발행자 뷰) |
| **F005** | 공유 링크 생성 | 견적서별 고유 토큰 기반 공유 URL 생성 및 클립보드 복사 | 클라이언트 전달의 핵심 수단 | 견적서 상세 페이지 (발행자 뷰) |
| **F006** | 견적서 웹 뷰어 (클라이언트) | 고유 URL로 접근한 클라이언트에게 견적서를 렌더링하여 표시 | 서비스의 핵심 가치 제공 | 견적서 웹 뷰어 페이지 |
| **F007** | PDF 다운로드 | 클라이언트가 현재 견적서를 PDF 파일로 다운로드 | 견적서의 최종 산출물 제공 | 견적서 웹 뷰어 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|---------------|------------|
| **F010** | 기본 인증 | 회원가입, 로그인, 로그아웃 (발행자만 해당, 이메일/비밀번호) | 발행자 데이터 보호를 위한 최소 인증 | 로그인 페이지, 회원가입 페이지 |
| **F011** | 토큰 유효성 검사 | 공유 URL의 토큰을 검증하여 유효하지 않으면 오류 안내 | 잘못된 URL 접근 시 사용자 경험 보호 | 견적서 웹 뷰어 페이지, 오류 안내 페이지 |

### 3. MVP 이후 기능 (제외)

- 견적서 상태 관리 (승인/거절/수정 요청 워크플로우)
- 클라이언트 전자서명
- 공유 링크 만료일 설정 및 비밀번호 보호
- 이메일 자동 발송 (URL 직접 공유 대신)
- 견적서 템플릿 커스터마이징
- 복수 노션 워크스페이스 연결
- 견적서 열람 이력 조회 (클라이언트가 언제 봤는지)
- 다국어, 다중 통화 지원

## 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 사용자 메뉴

| 항목 | 내용 |
|------|------|
| **역할** | 발행자(프리랜서/사업자)가 서비스에 인증하여 대시보드에 진입하는 진입점 |
| **진입 경로** | 서비스 최초 접근 시 자동 리디렉션, 헤더 "로그인" 버튼 클릭 |
| **사용자 행동** | 이메일과 비밀번호를 입력하고 로그인 버튼을 클릭한다. 계정이 없으면 회원가입 페이지로 이동한다 |
| **주요 기능** | 이메일/비밀번호 입력 폼, 입력값 유효성 검사 (Zod), 로그인 실패 시 오류 메시지 표시, **"로그인"** 버튼, 회원가입 페이지 링크 |
| **다음 이동** | 성공 → 견적서 목록 페이지, 실패 → 오류 메시지 표시 후 현재 페이지 유지 |

---

### 회원가입 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 사용자 메뉴

| 항목 | 내용 |
|------|------|
| **역할** | 신규 발행자가 서비스 계정을 생성하는 페이지 |
| **진입 경로** | 로그인 페이지의 "회원가입" 링크 클릭 |
| **사용자 행동** | 이메일, 비밀번호, 비밀번호 확인을 입력하고 가입 버튼을 클릭한다 |
| **주요 기능** | 이메일/비밀번호/비밀번호 확인 입력 폼, 비밀번호 일치 검사, 이메일 중복 확인, **"회원가입"** 버튼, 로그인 페이지 링크 |
| **다음 이동** | 성공 → 견적서 목록 페이지 (자동 로그인), 실패 → 오류 메시지 표시 후 현재 페이지 유지 |

---

### 노션 연동 설정 페이지

> **구현 기능:** `F001` | **메뉴 위치:** 발행자 메뉴 > 노션 연동 설정

| 항목 | 내용 |
|------|------|
| **역할** | 발행자가 노션 계정을 연결하고 견적서 데이터베이스 ID를 등록하여 동기화를 활성화하는 설정 페이지 |
| **진입 경로** | 발행자 메뉴의 "노션 연동 설정" 클릭, 또는 첫 로그인 시 연동 안내 배너에서 진입 |
| **사용자 행동** | 노션 OAuth 버튼으로 노션 계정을 연결하고, 견적서가 저장된 노션 데이터베이스 ID를 입력한 뒤 저장한다 |
| **주요 기능** | 노션 OAuth 연결 버튼 (연결 상태 표시 포함), 노션 데이터베이스 ID 입력 필드, 연결 테스트 (DB 접근 가능 여부 확인), **"저장"** 버튼, 연동 해제 버튼 |
| **다음 이동** | 저장 성공 → 견적서 목록 페이지 (첫 동기화 자동 실행), 실패 → 오류 메시지 표시 후 현재 페이지 유지 |

---

### 견적서 목록 페이지

> **구현 기능:** `F002`, `F003` | **메뉴 위치:** 발행자 메뉴 > 견적서 목록

| 항목 | 내용 |
|------|------|
| **역할** | 노션에서 동기화된 모든 견적서를 한눈에 확인하고 개별 견적서로 진입하는 발행자의 메인 화면 |
| **진입 경로** | 로그인 완료 후 자동 리디렉션, 발행자 메뉴 "견적서 목록" 클릭 |
| **사용자 행동** | 견적서 목록을 확인하고, "동기화" 버튼으로 노션 최신 데이터를 가져오며, 개별 견적서 행/카드를 클릭해 상세 페이지로 이동한다 |
| **주요 기능** | 견적서 목록 테이블 (견적서명, 클라이언트명, 총액, 작성일 표시), 노션에서 **"동기화"** 버튼 (수동 갱신), 견적서 행 클릭 시 상세 페이지 이동, 노션 미연동 시 연동 설정 유도 배너 |
| **다음 이동** | 견적서 행 클릭 → 견적서 상세 페이지 (발행자 뷰), "노션 연동 설정" 배너 클릭 → 노션 연동 설정 페이지 |

---

### 견적서 상세 페이지 (발행자 뷰)

> **구현 기능:** `F004`, `F005` | **메뉴 위치:** 견적서 목록 페이지에서 진입

| 항목 | 내용 |
|------|------|
| **역할** | 발행자가 특정 견적서의 내용을 확인하고, 클라이언트에게 전달할 공유 링크를 생성하는 페이지 |
| **진입 경로** | 견적서 목록 페이지에서 특정 견적서 행/카드 클릭 |
| **사용자 행동** | 견적서 내용을 웹에서 미리 확인하고, 공유 링크 생성 버튼을 클릭해 고유 URL을 클립보드에 복사한 뒤 클라이언트에게 전달한다 |
| **주요 기능** | 견적서 내용 미리보기 (발행자 정보, 클라이언트 정보, 품목 목록, 합계 금액), **"공유 링크 생성 및 복사"** 버튼 (클릭 시 고유 URL 클립보드 복사 + 복사 완료 피드백), 목록으로 돌아가기 링크 |
| **다음 이동** | "목록으로" 클릭 → 견적서 목록 페이지, 공유 링크 복사 성공 → 현재 페이지 유지 및 토스트 알림 |

---

### 견적서 웹 뷰어 페이지

> **구현 기능:** `F006`, `F007`, `F011` | **메뉴 위치:** 클라이언트가 공유 URL로 직접 접근

| 항목 | 내용 |
|------|------|
| **역할** | 클라이언트가 로그인 없이 고유 URL로 접근하여 견적서를 확인하고 PDF로 다운로드하는 서비스의 핵심 페이지 |
| **진입 경로** | 발행자로부터 전달받은 고유 URL을 브라우저 주소창에 입력하거나 링크 클릭 |
| **사용자 행동** | 견적서 내용을 웹에서 읽고, 필요 시 "PDF 다운로드" 버튼을 클릭하여 파일을 저장한다. 로그인은 불필요하다 |
| **주요 기능** | URL 토큰 유효성 검사 (F011), 견적서 전체 렌더링 (발행자 정보, 클라이언트 정보, 품목 테이블, 세금/할인/합계 금액, 발행일), **"PDF 다운로드"** 버튼 (서버 또는 클라이언트 사이드 PDF 생성 후 다운로드), 서비스 브랜딩 푸터 |
| **다음 이동** | 유효하지 않은 토큰 → 오류 안내 페이지로 자동 이동, PDF 다운로드 완료 → 현재 페이지 유지 |

---

### 오류 안내 페이지

> **구현 기능:** `F011` | **메뉴 위치:** 유효하지 않은 공유 URL 접근 시 자동 이동

| 항목 | 내용 |
|------|------|
| **역할** | 잘못되었거나 만료된 공유 URL로 접근한 클라이언트에게 원인과 안내 메시지를 제공하는 페이지 |
| **진입 경로** | 견적서 웹 뷰어 페이지에서 토큰 유효성 검사 실패 시 자동 리디렉션 |
| **사용자 행동** | 오류 메시지를 읽고 발행자에게 올바른 링크를 다시 요청한다 |
| **주요 기능** | 오류 원인 안내 메시지 ("유효하지 않은 링크입니다" 등), 발행자에게 문의 유도 안내, 서비스 홈으로 이동 링크 |
| **다음 이동** | "홈으로" 클릭 → 로그인 페이지 |

## 데이터 모델

### User (발행자 계정)

| 필드 | 설명 | 타입/관계 |
|------|------|-----------|
| id | 고유 식별자 | UUID |
| email | 로그인 이메일 | string |
| password_hash | 암호화된 비밀번호 | string |
| created_at | 가입일시 | timestamp |

### NotionIntegration (노션 연동 정보)

| 필드 | 설명 | 타입/관계 |
|------|------|-----------|
| id | 고유 식별자 | UUID |
| user_id | 발행자 계정 | → User.id |
| notion_access_token | 노션 OAuth 액세스 토큰 | string |
| notion_database_id | 연결된 견적서 DB ID | string |
| connected_at | 연동일시 | timestamp |

### Invoice (견적서)

| 필드 | 설명 | 타입/관계 |
|------|------|-----------|
| id | 고유 식별자 | UUID |
| user_id | 발행자 계정 | → User.id |
| notion_page_id | 원본 노션 페이지 ID | string |
| share_token | 공유 URL용 고유 토큰 | string |
| data | 견적서 전체 데이터 (JSON) | jsonb |
| synced_at | 마지막 동기화 일시 | timestamp |

### InvoiceData (견적서 JSON 내부 구조 참고)

| 필드 | 설명 |
|------|------|
| title | 견적서 제목 |
| issuer | 발행자 정보 (이름, 연락처, 사업자번호 등) |
| client | 클라이언트 정보 (이름, 연락처) |
| items | 품목 목록 (품목명, 수량, 단가, 금액) |
| total_amount | 합계 금액 |
| issued_at | 견적서 발행일 |
